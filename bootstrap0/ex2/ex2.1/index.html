Exercise 2.1 - Bootstrap Directory Structure

css/

Contains precompiled Bootstrap CSS files: bootstrap.css, bootstrap.min.css, bootstrap-grid.css, bootstrap-reboot.css, and their source maps.

js/

Contains precompiled Bootstrap JavaScript files: bootstrap.js, bootstrap.min.js, bootstrap.bundle.js, bootstrap.bundle.min.js (includes Popper), and source maps.

icons/ (optional)

Contains Bootstrap Icons font files, CSS for icons, and SVG icons. Provides over 2000 free icons for use in Bootstrap projects.
