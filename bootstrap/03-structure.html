Bootstrap Directory Structure

A downloaded Bootstrap package contains these key folders:

css/
  • bootstrap.min.css — main stylesheet
  • bootstrap-grid.min.css — grid only
  • bootstrap-reboot.min.css — reset only
js/
  • bootstrap.bundle.min.js — JS + Popper
  • bootstrap.min.js — JS only (no Popper)
icons/ (optional)
  • SVG icons for use in UI
  • Font files for icon fonts
